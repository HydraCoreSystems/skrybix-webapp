# Fixtures

`pre_20260815120000_schema.sql` is a byte-for-byte checked-in copy of
`supabase/schema.sql` as it existed at commit
`a4f69f1c94d807c5df8c50926d00eccf5e14e8eb` (the merge of PR #11, the last
commit before `supabase/migrations/20260815120000_existing_id_as_commerce_sku.sql`
existed). It's used by `supabase/verify_commerce_sku_migration.sh` as the
"pre-migration" baseline for the upgrade-path and preflight
phase-detection checks.

Deliberately not re-derived from `origin/master` at CI-run time: once the
existing-ID-as-SKU correction merges, `origin/master` *is* the corrected,
post-migration schema, so a script that re-reads `origin/master` at
"pre-migration" time starts asserting the wrong thing the moment its own
PR merges (this happened for real -- see the git history of
`verify_commerce_sku_migration.sh` around the fix that added this
fixture). A file frozen to an explicit historical SHA can't drift out
from under the script the way a branch ref can.

Do not edit this file to "update" it as the schema evolves -- it is
deliberately a historical snapshot, not a live copy. If a future
migration needs its own frozen pre-state fixture, add a new file named
for that migration rather than changing this one.
